CoverLink가 일하는 방식

같은 원본, 같은 절차로 업무를 넓혀 갑니다

위키 하나를 원본으로, 에이전트를 만들고 업무를 넓힙니다.

  1. 01 SOURCE OF TRUTH (SOT) 원본을 봅니다

    CoverLink는 위키를 원본(SOT)으로 두고, 에이전트는 그 원본에서 만들어집니다

    • 개발 표준 · 업무 정의는 OKF 위키 한 곳에
    • 모든 에이전트가 같은 원본을 기준으로 일합니다
    예개발 표준 위키 · 에이전트 위키
    에이전트를 만드는 기준
  2. →
  3. 02 AGENT PLAYBOOK 절차대로 일합니다

    에이전트는 현업 전문가가 정한 플레이북대로 일하고, 판단이 어려운 건은 사람에게 넘깁니다

    • 검증된 업무 워크플로우를 그대로 실행
    • 단계 · 도구 · 사람 확인 지점(HITL)을 미리 정의
    예AI 가입설계 워크플로우
    요청 → 추천 → 설계 → 검증 → 담당자 확인
  4. →
  5. 03 EXPANDING DOMAIN 업무가 넓어집니다

    위키를 더할수록 같은 방식으로 새 업무 에이전트가 늘어납니다

    • 코딩 어시스턴트로 같은 도구 · 같은 품질
    • 가입설계 → 활동 관리 → 보장분석 → UW → 보험금 지급
    예가입설계에서 다른 업무로
    활동 관리 · 보장분석 · 언더라이팅

원본을 보고 → 절차대로 일하고 → 업무가 넓어집니다
