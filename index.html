Pre · During · Post — 3단 통제
PRE
Built-in Guardrails

사용자 입력(금칙어·PII·Injection) 차단을 가드레일로 강제 적용해 보안 이슈를 사전 차단합니다.

DURING
Custom HITL Checkpoints

보험사가 직접 정의한 검수 지점에서 고위험 행위는 반드시 사람이 승인합니다 — 최종 판단은 언제나 사람의 몫입니다.

POST
Audit Trail

모든 AI 판단의 근거를 단계별로 로깅·저장해, 사후 감사와 규제 대응에 즉시 대응할 수 있습니다.

AI는 자율 판단하지 않습니다 — 사전 가드레일 · 실행 중 HITL · 사후 감사, 모든 단계에서 통제할 수 있습니다.

SOLUTION 04 · 어떤 구조인가

쓰던 스택 위에 그대로 얹힙니다

Java 네이티브로 만들어 MCP 표준으로 연결합니다. 기존 금융 SI 환경에 API 기반으로 접목되며, 별도 인프라·인력이 필요 없습니다.

AI Agent Platform · 4-Layer Architecture
L1 · User Interface자연어 채팅 · 결과 시각화 · 상품·특약 정보 조회
L2 · AI Agent LayerPlanner + 5 Specialist Agents · Multi-Agent Orchestration
L3 · Domain Knowledge EngineKnowledge Base · Guardrails · 언더라이팅·선심사 체크
L4 · MCP IntegrationGateway · Tool · Skill · 표준 프로토콜로 기존 보험 시스템 연결
L1–L2

Conversational UX + Plan-Centric

자연어 채팅으로 설계사 진입장벽 제로 — Planner가 5 Specialist Agent에게 업무를 자율 분담합니다.

L3

Domain Knowledge Engine

보험 용어·약어·인수기준을 검증된 정책으로 강제 적용하는 Knowledge Base + Guardrails입니다. 온톨로지·벡터 DB로 업무 위키가 여기에 적재됩니다.

L4

MCP Integration

표준 프로토콜(Gateway)로 기간계·CRM 등 기존 보험 시스템과 즉시 연결됩니다.
